# Kloo (working name)

Save reels from Instagram, TikTok and YouTube; Kloo reads them on your phone
and answers questions about them. Your saves never leave your phone.

This repository is the company's shared memory: product rules, architecture,
decisions, the AI agent team, and the evaluation suites that keep us on course.

- `CLAUDE.md` — how Claude and the agents work here
- `PRINCIPLES.md` — the non-negotiables
- `docs/architecture.md` — the stack
- `docs/team.md` — the founders and the ten agents
- `docs/decisions/` — decision records
- `evals/` — evaluation suites, thresholds and runners
- `.claude/agents/` — agent definitions

Status: pre-build. Apps, core and backend folders are created as work starts.
