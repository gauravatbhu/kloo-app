nightly job exists and no app harness produces results. I ran

is also synthetic.

**Real measurements this week (speech only, desktop CPU, open data, not yet on main):**
- Hindi + Hinglish, same 240 FLEURS + MUCS clips (target `speech.wer_hi` ≤ 35%):
  Oriserve Apex 27.2% ✓, Oriserve Prime 27.2% ✓, Whisper small Hindi
  fine-tune 35.1% (borderline: 11.7% on plain Hindi, 78% on Hinglish),
  stock Whisper small 62.0% ✗.
- English, Whisper small, 200 FLEURS clips: 7.3% ✓ (target ≤ 15%).
- Source: `evals/benchmarks/speech-round2/README.md` in PR #5 (open).
- Not measured yet: the natural-speech sets (IndicVoices, Lahaja, Svarah) and
  IndicConformer. Hugging Face returned 403 because access was not granted. These
  sets sound more like reels than FLEURS, so expect higher error rates.

**Risk that moved:** speed. On desktop CPU, Apex takes 1.77 s per second of audio.
A 60 s reel would take well over 30 s on a phone CPU, so
`speed.reel_read_seconds_p50` ≤ 30 s is at risk. Nothing has been measured on a
phone yet.

## Principles check
No breach of PRINCIPLES.md in what landed. No product code exists yet, so
the principles had little to touch. Near misses and gaps:

1. **Required reviews skipped (CLAUDE.md, step 4).** PR #4 changed the
   network allowlist and crossed layers, so it needed `security-privacy` and
   `architect` reviews. It was merged with no reviews recorded on GitHub.
   PRs #1–#3 also have no recorded reviews. The change itself is sound: it
   removes a network host. But the process was skipped. **Fix:** from now on,
   each required review is posted as a comment on the PR before merging.
2. **Principle 12 (claims are tested).** The design system ships the copy
   "Answered on this phone" and permission sentences. No tests in
   `evals/privacy/` cover them yet. This is fine while there is no app, and
   blocks shipping until the tests exist.
3. **Licence gap.** PR #5 proposes Apex as the main model, but its licence and
   training-data provenance are not in the "Licences recorded" table of
   `docs/research/speech-model-options.md`. Prime's licence is recorded. This
   must be checked before Apex is bundled.
4. **Benchmark data.** `ci/speech-results` publishes per-clip transcripts for
   FLEURS (CC BY 4.0) and MUCS (CC BY-SA 4.0). Both licences allow this with
   attribution. Gated-set transcripts are stripped by design, and none have
   run yet. Before the gated sets run, check that `ATTRIBUTION.md` covers the
   published rows and that no gated rows appear.
5. **Eval cadence not running.** `docs/team.md` promises nightly reports.
   None exist, so the drift alarm can't fire.
6. CI secret handling in the round-2 workflow is fine: `persist-credentials: false`,
   and `HF_TOKEN` is passed only to the download and model steps.
